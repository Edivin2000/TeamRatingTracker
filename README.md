# ATOM-GAME Рейтинговая Система

![ATOM-GAME Logo](attached_assets/Group.png)

## О проекте

Рейтинговая система для ATOM-GAME в Балаково на сезон 2025 с призовым фондом 150 000 рублей. Система позволяет отслеживать рейтинг команд, управлять баннерами, партнерами и дизайном сайта через административную панель.

Проект разработан при поддержке **Фонда «АТР АЭС» и АО «Концерн Росэнергоатом»**.

## Особенности

- 🏆 Динамические рейтинги команд и визуальный пьедестал для топ-3
- 📊 Индикаторы изменения позиций команд
- 🖼️ Ротация рекламных баннеров
- 👥 Раздел партнеров с логотипами
- ⏱️ Обратный отсчет до важных событий
- 🔐 Административный интерфейс для управления контентом
- 🎨 Настраиваемое оформление через админ-панель
- 📱 Адаптивный дизайн для всех устройств

## Технологии

- **Frontend:** React, TypeScript, TailwindCSS, shadcn/ui
- **Backend:** Node.js, Express
- **База данных:** PostgreSQL с Drizzle ORM
- **Аутентификация:** Passport.js с сессиями
- **Деплой:** PM2, Nginx, Let's Encrypt

## Запуск для разработки

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

## Деплой на сервер

```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/atom-game-rating.git

# Перейти в директорию проекта
cd atom-game-rating

# Выполнить скрипт установки
chmod +x deploy.sh
sudo ./deploy.sh
```

## Структура проекта

```
client/             # Frontend React-приложение
  ├── src/          # Исходный код
  │   ├── assets/   # Статические ресурсы
  │   ├── components/ # UI компоненты
  │   ├── hooks/    # React хуки
  │   ├── lib/      # Вспомогательные функции
  │   ├── pages/    # Страницы приложения
  │   └── ...
server/             # Backend Express-сервер
  ├── index.ts      # Точка входа
  ├── routes.ts     # API маршруты
  ├── storage.ts    # Хранилище данных
  └── ...
shared/             # Общий код
  └── schema.ts     # Схема базы данных
```

## Скрипты

- `npm run dev` - Запуск в режиме разработки
- `npm run build` - Сборка проекта
- `npm run db:push` - Обновление схемы базы данных
- `npm start` - Запуск в продакшн режиме

## Скрипты для сервера

- `deploy.sh` - Полная установка и настройка приложения
- `backup.sh` - Создание резервных копий
- `update.sh` - Обновление приложения
