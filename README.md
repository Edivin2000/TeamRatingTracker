# ATOM-GAME | Система рейтинга команд

Платформа для отслеживания рейтинга команд, созданная для ATOM-GAME в Балаково.

## Описание

Система рейтинга команд ATOM-GAME - это веб-приложение, разработанное для турнира ATOM-GAME в Балаково, сезон 2025 года с призовым фондом 150 000 рублей. Проект поддерживается Фондом «АТР АЭС» и АО «Концерн Росэнергоатом».

### Основные функции

- Публичная страница с рейтингом команд и подиумом лидеров
- Индикаторы изменения позиций команд
- Партнеры проекта с логотипами
- Рекламные баннеры с ротацией
- Таймер обратного отсчёта 
- Административная панель для управления данными

## Установка

### Требования

- Node.js v20+
- PostgreSQL 16+
- Nginx
- PM2

### Быстрая установка

Для быстрой установки выполните следующие команды:

```bash
# Клонирование репозитория
git clone https://github.com/Edivin2000/TeamRatingTracker.git
cd TeamRatingTracker

# Запуск скрипта установки
sudo ./install.sh
```

После установки сайт будет доступен по адресу сервера.

### Доступ к административной панели

Для доступа к административной панели необходимо:
1. Нажать 5 раз в правый верхний угол страницы
2. Ввести логин: `admin`
3. Ввести пароль: `Atom&Game#2025!`

## Обслуживание

### Обновление

Для обновления проекта выполните:

```bash
cd /var/www/atomgameblk
./update.sh
```

### Резервное копирование

Для создания резервной копии базы данных:

```bash
cd /var/www/atomgameblk
./backup.sh
```

### Управление сервером

- Просмотр логов: `pm2 logs atom-game`
- Перезапуск приложения: `pm2 restart atom-game`
- Статус приложения: `pm2 status`

## Технологии

- Frontend: React, TypeScript, TailwindCSS, Shadcn/UI
- Backend: Node.js, Express, Drizzle ORM
- База данных: PostgreSQL
- Деплой: PM2, Nginx
