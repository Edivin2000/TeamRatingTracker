# ATOM-GAME - Платформа для команд и рейтингов

## Инструкция по установке на сервер Ubuntu

### Для установки на сервер (atomgameblk.ru):

1. Скопируйте все файлы проекта на сервер
2. Запустите скрипт установки с правами администратора:
   ```
   sudo ./deploy-to-server.sh
   ```
3. После завершения базовой настройки переходим в директорию проекта:
   ```
   cd /var/www/atomgame
   ```
4. Запускаем скрипт окончания установки:
   ```
   sudo ./finish-setup.sh
   ```

После этого сайт будет доступен по адресу: https://atomgameblk.ru

### Полезные команды после установки:
- Перезапуск приложения: `pm2 restart atom-game-server`
- Просмотр логов: `pm2 logs atom-game-server`
- Статус приложения: `pm2 status`
- Остановка приложения: `pm2 stop atom-game-server`

## Исправление ошибок на локальном сервере

### Исправление сохранения изображений и порта:

Если у вас возникли проблемы с сохранением изображений или нужно изменить порт:

1. Запустите скрипт `fix-images-server.sh`:
   ```
   chmod +x fix-images-server.sh
   ./fix-images-server.sh
   ```

2. Запустите сервер на порту 5001:
   ```
   ./start-server-5001.sh
   ```
