# ATOM-GAME - Система рейтинга команд

## Инструкция по установке

Есть три способа установки системы:

### 1. Полностью автоматическая установка

Для полностью автоматической установки на IP-адрес 193.109.78.85 с портом 5001, выполните:

```bash
# 1. Скачайте скрипт auto_install.sh
wget https://path-to-your-storage/auto_install.sh

# 2. Сделайте скрипт исполняемым
chmod +x auto_install.sh

# 3. Запустите скрипт (обязательно с правами root)
sudo ./auto_install.sh
```

**Важно:** В скрипте уже указан правильный URL репозитория: `GIT_REPO_URL="https://github.com/Edivin2000/TeamRatingTracker.git"`

Скрипт установит:
- Node.js 18.x
- PostgreSQL
- PM2
- Nginx
- Клонирует репозиторий из GitHub
- Настроит базу данных
- Настроит переадресацию через Nginx
- Запустит приложение

### 2. Установка с настройкой параметров

Если вы хотите настроить параметры установки (путь, имя базы данных и т.д.):

```bash
# 1. Скачайте скрипт deploy.sh
wget https://path-to-your-storage/deploy.sh

# 2. Сделайте скрипт исполняемым
chmod +x deploy.sh

# 3. Запустите скрипт (обязательно с правами root)
sudo ./deploy.sh
```

### 3. Ручная настройка только Node.js

Если вам нужно только настроить правильную версию Node.js и npm:

```bash
# 1. Скачайте скрипт setup_nodejs.sh
wget https://path-to-your-storage/setup_nodejs.sh

# 2. Сделайте скрипт исполняемым
chmod +x setup_nodejs.sh

# 3. Запустите скрипт (обязательно с правами root)
sudo ./setup_nodejs.sh
```

## Возможные проблемы и их решение

### 1. Ошибка "The following packages have unmet dependencies"

Если вы видите ошибку с unmet dependencies (неудовлетворенные зависимости) для npm, используйте скрипт `setup_nodejs.sh`, который правильно установит Node.js вместе с npm.

### 2. Проблемы с доступом к API

После установки проверьте:
- Работает ли сервис: `pm2 status`
- Логи приложения: `pm2 logs atomgame`
- Настройки Nginx: `nginx -t`

## Важные команды

```bash
# Просмотр логов приложения
pm2 logs atomgame

# Перезапуск приложения
pm2 restart atomgame

# Создание резервной копии базы данных
/var/www/atomgame/backup.sh
```

## Структура директорий после установки

```
/var/www/atomgame/
├── client/           # Фронтенд приложения
├── server/           # Бэкенд приложения
├── shared/           # Общие компоненты (схемы и типы)
├── dist/             # Скомпилированные файлы
├── backups/          # Директория для резервных копий
├── logs/             # Логи приложения
├── .env              # Конфигурация приложения
└── ecosystem.config.js  # Конфигурация PM2
```
